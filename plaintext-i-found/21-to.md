# 21 — TO

*Candidate continuation after THEN: **THE KEY IS TO GO …***

This is **candidate block 21**, following **THE** (18), **KEY** (19), and **IS** (20). These proposals are **not** part of the original 17-block reconstruction, which ends at **THEN**; **DEATH** is block 13. The original 17 blocks contain **16 observed transitions** used to develop Reports 01–06.

The proposed ciphertext is `U–NG`, read **diagonally up-right**. A vertical `X–M–X` mirror supplies the derived key `X–E–X`, and subtraction modulo 29 gives **`T · O` → TO**.

The basic operations from Report 00 remain in use: **transform the original key-node center by Euler's totient, calculate the Möbius rotation, and subtract the key modulo 29**. Its earlier **coordinate selector** and **CENTER/OUTER endpoint heuristic** are **not mandatory after THEN**. The continuation is instead tested against **Reports 01–06**. Passing those tests means that this *selected* route is internally consistent; it does not prove a unique or authentic Cicada 3301 plaintext.

**Notation:** All matrix coordinates are **1-based `(row, column)`**. Rune indices refer to the 29-rune alphabet, **not** Gematria Primus prime values. `φ` denotes Euler's totient function, and `μ` denotes the Möbius function. For a cell `(r,c)`, the position indices used by the reports are:

## 1. Locate the original key node

The selected **vertical mirror** is `X–M–X`. Its center is **`M (8,25)`**, and the outer `X` runes lie **three rows** above and below it.

| Mirror | Upper outer | Center | Lower outer | Radius |

The geometry is exact: `(5 + 11) / 2 = 8`, and all three cells are in **column 25**.

This is the **selected original node**, not a node uniquely determined by the predicted signature alone. Its center parity and derived-key signature will be checked against the preceding IS block.

## 2. Derive and align the decryption key

### Transform the center rune

Keep the outer `X` runes unchanged. Apply Euler's totient function **only to the original center `M`**:

`M = 19 → φ(19) = 18 → E`

The unrotated key is therefore:

`X–M–X → X–E–X`

### Calculate the Möbius signature

Apply `φ` followed by `μ` to each rune index in the **derived key**:

| Derived key rune | Rune index | Totient | Möbius value |
|:---:|:---:|:---:|:---:|
| X | 14 | `φ(14) = 6` | `μ(6) = +1` |
| E | 18 | `φ(18) = 6` | `μ(6) = +1` |
| X | 14 | `φ(14) = 6` | `μ(6) = +1` |

**Totient signature:** `(6, 6, 6)`  
**Möbius signature:** `(+1, +1, +1)`

The cyclic left-rotation phase is:

`p = (1 + 1 + 1) mod 3 = 0`

No rotation is needed. **Final repeating key: `X–E–X`.** The two-rune ciphertext will use only `X–E`; the third key rune is unused.

## 4. Predict the ciphertext geometry (Reports 02–03)

### Predict the reading axis (Report 03)

For the current IS block, use beginning `B = (18,7)`, endpoint `E = (19,6)`, and **original node center** `M = (17,9)`.

First:

`A = n₂(B) + n₀(M) = 264 + 441 = 705`

Here `705 = 3 × 5 × 47`, so **`μ(705) = −1`**.

Next:

`G = gcd(n₁(E), n₂(E)) = gcd(144,238) = 2`

Thus **`μ(G) = μ(2) = −1`**, and:

`q_axis = μ(705) + μ(2) = −1 − 1 = −2`

A negative result predicts the next ciphertext axis to be **DIAGONAL**. It does not independently specify whether that diagonal runs up-right or down-right.

### Predict the leftmost boundary (Report 02)

Use the IS **endpoint** `OE (19,6)` and the **original** IS center's rune index `I = 10`:

`n₃(19,6) = 27(27 − 6) + 19 = 586`

`586 = 2 × 293`, so **`μ(586) = +1`**. Also, `φ(10) = 4`.

`τ_next = [μ(586) + φ(10)] mod 2 = (1 + 4) mod 2 = 1`

**Predicted boundary: BEGINNING.** The next ciphertext's leftmost cell must be its **first** cell. Combined with DIAGONAL, this means the reading proceeds **toward increasing column numbers**.

## 5. Check the incoming ray (Report 06)

The incoming ray is **not** the reading direction within TO. It connects the **leftmost cell of IS**, `OE (19,6)`, with the **beginning of TO**, `U (9,16)`:

`Δ = (9,16) − (19,6) = (−10,+10)`

This is an exact **up-right** diagonal displacement. Its eight-ray deviation is:

`d₈ = min(|−10|, |+10|, ||−10| − |+10||) = min(10,10,0) = 0`

Report 06 calculates the permitted deviation from the **previous endpoint** `OE (19,6)`:

- `n₀(19,6) = 492`, and **`μ(492) = 0`** because `492` contains `2²`.
- `n₃(19,6) = 586`, and **`μ(586) = +1`**.

The one-cell allowance is enabled **only if both Möbius values are zero**. Here they are not, so **`q = 0`**.

**`d₈ = 0 ≤ q = 0` — pass.** The proposed TO beginning lies **exactly** on an allowed eight-direction ray. This constraint does not specify which ray, how far to travel, or which two-rune sequence to choose.

`Plaintext index = (ciphertext index − key index) mod 29`

| (9,16) | U = 1 | X = 14 | `1 − 14 ≡ 16` | **T** |

Both modular subtractions are exact. The result uses **two ciphertext cells** and the first **two elements** of the three-rune key `X–E–X`.
