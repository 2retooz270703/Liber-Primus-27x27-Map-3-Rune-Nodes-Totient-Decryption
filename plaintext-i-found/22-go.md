# 22 — GO

This is **candidate block 22**, completing the proposed five-block continuation **THE (18) → KEY (19) → IS (20) → TO (21) → GO (22)**. It is **not** part of the original 17-block reconstruction, which ends at **THEN**; **DEATH** occurs at block 13. The original reconstruction provides **16 observed transitions**, from which Reports 01–06 were developed.

The proposed ciphertext is `H–C`, read **rightward** on row 9. The original vertical mirror `TH–G–TH` produces the constant derived key `TH–TH–TH`. Subtraction modulo 29 gives **`G · O` → GO**.

The basic decryption operations from Report 00 are retained: **apply Euler's totient to the original mirror's center, rotate according to its Möbius signature, and subtract the aligned key modulo 29**. The earlier **coordinate selector** and **CENTER/OUTER endpoint heuristic** from Report 00 are **not mandatory after THEN**. The selected continuation is instead checked against **Reports 01–06**. Agreement with those reports establishes consistency with this model, **not uniqueness or authenticity**.

## 2. Derive and align the decryption key

### Transform the center rune

Keep the outer `TH` runes unchanged. Apply Euler's totient **only to the original center `G`**:

`G = 6 → φ(6) = 2 → TH`

Therefore:

`TH–G–TH → TH–TH–TH`

Unlike the preceding blocks, **all three derived key runes are identical**.

### Calculate the Möbius signature

Apply `φ`, then `μ`, to each index in the **derived** key:

| Derived rune | Rune index | Totient | Möbius value |
|:---:|:---:|:---:|:---:|
| TH | 2 | `φ(2) = 1` | `μ(1) = +1` |
| TH | 2 | `φ(2) = 1` | `μ(1) = +1` |
| TH | 2 | `φ(2) = 1` | `μ(1) = +1` |

**Totient signature:** `(1, 1, 1)`  
**Möbius signature:** `(+1, +1, +1)`

The cyclic left-rotation phase is:

`p = (1 + 1 + 1) mod 3 = 0`

No rotation changes the key. **Final repeating key: `TH–TH–TH`**. Since the proposed ciphertext contains only two runes, both subtract **`TH = 2`**.
