## 2. Derive and align the decryption key

### Transform the center rune

Keep the two outer `W` runes and apply Euler's totient function **only to the original center `I`**:

`I = 10 → φ(10) = 4 → R`

Hence the original mirror generates the **unrotated key**:

`W–I–W → W–R–W`

### Calculate the Möbius signature

Apply `φ`, then `μ`, to the **derived key** rather than to the original mirror:

| Derived key rune | Rune index | Totient | Möbius value |
|:---:|:---:|:---:|:---:|
| W | 7 | `φ(7) = 6` | `μ(6) = +1` |
| R | 4 | `φ(4) = 2` | `μ(2) = −1` |
| W | 7 | `φ(7) = 6` | `μ(6) = +1` |

**Totient signature:** `(6, 2, 6)`  
**Möbius signature:** `(+1, −1, +1)`

The phase is the sum of the Möbius values modulo 3:

`p = (1 − 1 + 1) mod 3 = 1`

Rotate the unrotated key **one position to the left**:

`W–R–W → R–W–W`

**Final repeating decryption key: `R–W–W`.** Only its first two elements are needed for a two-rune ciphertext.

## 4. Predict the ciphertext geometry and check the incoming ray

### Predict the reading axis (Report 03)

For KEY, use its ciphertext beginning `B = (21,4)`, endpoint `E = (19,4)` and **original** key-node center `M = (12,16)`.

First compute:

`A = n₂(B) + n₀(M) = 186 + 313 = 499`

Then compute:

`G = gcd(n₁(E), n₂(E)) = gcd(90,240) = 30`

Since `499` is prime, **`μ(499) = −1`**. And `30 = 2 × 3 × 5`, so **`μ(30) = −1`**.

Therefore:

`q_axis = μ(499) + μ(30) = −1 − 1 = −2`

A **negative** value predicts the next ciphertext axis to be **DIAGONAL**.

### Predict which boundary is leftmost (Report 02)

Use the KEY endpoint `EA (19,4)` and the rune index of the **original center H = 8**:

`n₃(19,4) = 27(27 − 4) + 19 = 640`

`μ(640) = 0`, while `φ(8) = 4`. Thus:

`τ_next = [μ(640) + φ(8)] mod 2 = (0 + 4) mod 2 = 0`

`τ = 0` predicts that the next ciphertext's **leftmost cell is its END**. Combined with the DIAGONAL axis, this requires reading **toward the left**. The rule does not by itself choose **up-left versus down-left**.

### Check the incoming Möbius-gated ray (Report 06)

Both are zero, so **`q = 1`** permits up to a one-cell deviation. This candidate needs none:

**`d₈ = 0 ≤ q = 1` — pass.** The gate permits this start; it does **not** specify the ray direction or distance, and does not identify `X (18,7)` uniquely.
